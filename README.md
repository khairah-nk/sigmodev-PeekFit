# PeekFit

PeekFit is a modern fitness landing page designed for a gym or wellness studio. The project presents a polished member dashboard with an active status badge, personal trainer highlights, and a curated list of today’s classes.

## Overview

This project is built as a lightweight static website using plain HTML, CSS, and JavaScript. It focuses on a clean, high-energy fitness aesthetic with responsive cards and a strong visual hierarchy.

## Features

- Active member status panel
- Personalized welcome header with a fitness-focused hero section
- Trainer profile cards with specialties and schedules
- Class listing for the day with time, coach, and call-to-action buttons
- Responsive layout for desktop and smaller screens
- Simple, framework-free setup with no build step required

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

- `index.html` — main page structure and content
- `styles.css` — complete styling, layout, and responsiveness
- `script.js` — JavaScript file for future interactivity and logic

## Run Locally

Because this is a static site, you can run it in a browser directly or serve it locally with a simple HTTP server.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Use a local server

From the project root, run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a front-end mockup and currently serves as a landing page rather than a full app with authentication or backend features. The structure is ready for future enhancements such as booking flows, class filtering, and dynamic trainer data.
